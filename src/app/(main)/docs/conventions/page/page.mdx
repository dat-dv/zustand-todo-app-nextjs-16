# Page Layer

Điểm bắt đầu của một tuyến đường (Route).

---

## Trách nhiệm

- **Server Component**: Fetch data trực tiếp từ DB/Service (async).
- **SEO**: Định nghĩa Title/Description qua `Metadata`.
- **Hydration**: Truyền data từ Page xuống `Provider` để hydrate Store (chống Flicker UI).
