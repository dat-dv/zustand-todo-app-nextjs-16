# Use Case Layer

Nơi thực thi một **User Story** cụ thể. Kết nối giữa Hook, Domain và Infrastructure.

---

## Trách nhiệm

- **Điều phối**: Gọi Repository lấy data.
- **Business Logic**: Áp dụng các quy tắc kiểm tra (ví dụ: Task đã xong thì không cho xóa).
- **Độc lập**: Không quan tâm UI là gì (React/Vue/Terminal).

---

## Ví dụ

```typescript
// src/domain/todo/use-cases/create.use-case.ts
export class CreateTodoUseCase extends UseCase<Request, Promise<ITodo>> {
  constructor(private repository: ITodoRepository) {
    super();
  }

  async execute(req: Request): Promise<ITodo> {
    // 1. Check logic (nếu có)
    if (!req.title) throw new Error('Cần nhập tiêu đề');

    // 2. Lưu xuống DB qua Repo
    return await this.repository.create(req);
  }
}
```

## Quy tắc

- Đặt tên: `[Hành động][Tên Module]UseCase` (vd: `DeleteTodoUseCase`).
- **Không** khởi tạo Repository trực tiếp — truyền qua constructor để dễ Unit Test (Mocking).
