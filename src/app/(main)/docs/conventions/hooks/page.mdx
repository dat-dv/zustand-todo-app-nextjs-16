# Hook Layer

Hook là **Adapter** — cầu nối giữa UI và Logic nghiệp vụ.

---

## Trách nhiệm

- Nhận action từ UI → validate (Zod) → gọi UseCase.
- Quản lý optimistic update + rollback nếu lỗi.
- Cập nhật Store sau khi UseCase trả về kết quả.

## Optimistic Update

```typescript
// useTodoAction.ts
async function deleteTodo(id: string) {
  // 1. Cập nhật Store ngay (optimistic)
  store.removeTodo(id);

  try {
    // 2. Gọi UseCase
    await deleteTodoUseCase.execute(id);
  } catch {
    // 3. Rollback nếu lỗi
    store.restoreTodo(id);
    toast.error('Xóa thất bại');
  }
}
```

---

## Quy tắc

- Component chỉ gọi hàm từ Hook, không tự gọi Store.
- Dùng `useShallow` khi lấy nhiều field từ Store cùng lúc.
