## 2. 4 Vòng tròn (Văn nói)

- **Trắng (Lõi)**: `Domain Entity` (ITodo) + `Use Case`. Đây là nơi chứa logic "hái ra tiền".
- **Xanh (Adapter)**: `Repository`, `Mapper`, `Hooks`. Cầu nối cho dữ liệu đi vào/ra.
- **Vàng (Framework)**: `React`, `Zustand`, `SQLite`. Đồ chơi để app chạy được.

---

## 3. Tại sao lại làm phức tạp thế?

- **Dễ test**: Mocking Repo cực nhanh.
- **Dễ đổi đồ**: Nếu sau này muốn đổi sang `PostgreSQL` hoặc `MobX` thì phần logic `Domain` vẫn giữ nguyên 100%.
- **Dễ đọc**: File nằm đâu là biết nó làm gì ở đó.
