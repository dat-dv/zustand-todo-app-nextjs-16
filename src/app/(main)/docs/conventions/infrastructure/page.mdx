# Infrastructure Layer

Nơi cầu nối giữa app và thế giới bên ngoài: **Database**, **API**, **LocalStorage**.

---

## 1. Repository Pattern

- Triển khai các Interface từ Domain Layer.
- **Mocking**: Giúp unit test dễ dàng (đổi từ gọi API sang gọi Mock data).

---

## 2. Mapper & DTO

- **DTO**: Định dạng dữ liệu từ API/DB (vd: `todo_id` — snake_case).
- **Domain Model**: Định dạng dữ liệu UI muốn dùng (vd: `todoId` — camelCase).
- **Mapper**: Chuyển đổi giữa 2 thằng trên.

```typescript
// todo.mapper.ts
export class TodoMapper {
  static toDomain(dto: TodoDTO): ITodo {
    return {
      id: dto.todo_id,
      title: dto.title,
    };
  }
}
```

## 3. Quy tắc

- **Không** chứa logic nghiệp vụ (vd: check completed đã xóa được chưa).
- Mọi logic check business đó **bắt buộc** phải chuyển lên **UseCase**.
- Repository chỉ làm nhiệm vụ: **Lấy / Lưu dữ liệu**.
